# 工作表分頁色彩

開啟有設定分頁色彩的 XLSX 後，底部工作表分頁會顯示原檔顏色。未選取分頁使用原色，文字依明暗使用黑色或白色；選取時改用淡色底與原色底線，保留辨識度。沒有設定色彩的工作表沿用原本外觀。

- 支援 RGB、主題色與明暗調整（tint），以及索引色；主題色使用原活頁簿的配色解析。
- 切換、改名、移動及復原後，顏色仍跟著原工作表。隱藏工作表的顏色仍保留；新增工作表使用預設樣式。
- XLSX 原檔另存時，保留原有主題色參照。WWX 保存解析後的 RGB，轉回 XLSX 時使用相同 RGB，避免新活頁簿的主題改變分頁顏色。
- 無色、自動色或無效色彩使用預設分頁外觀。
- 在分頁上按右鍵，選「分頁色彩…」即可選擇色彩；「無色彩」恢復預設外觀。支援復原／重做，Escape 取消選色。
- 變更色彩後使用明確 RGB 保存；清除色彩也會移除原檔的主題色與 tint，避免重新開啟後舊色彩再出現。

`test_data/test7.xlsx` 的實際解析色彩：

| 工作表 | RGB | 顏色 |
| --- | --- | --- |
| 學期 | `262626` | 深灰 |
| 學分 | `404040` | 灰色 |
| 預算 | `38722A` | 深綠 |
| 書籍 | `1B6567` | 深青 |


此範例的欄樣式涵蓋整張工作表。XLSX 匯出會將連續且相同的欄樣式合併寫入，避免 WWX → XLSX 時逐欄重建造成過長等待；個別欄與儲存格格式仍保留。

## 驗證

`test7.xlsx` 原生視窗 30／30 項、一般原生編輯 255／255 項、前端 241 項與完整 Go 測試通過，詳見 [驗收紀錄](sheet-tab-colors-selftest.md)。

Go 測試涵蓋色彩解析、主題／索引色、XLSX／WWX 往返、改名移動、隱藏分頁，以及整張工作表的欄樣式與個別格式保留。前端測試涵蓋文字對比、選取底色及無效色彩處理。

原生視窗驗收：

```bash
WW_SELFTEST=1 WW_XLSX_FIXTURE="$PWD/test_data/test7.xlsx" WW_BENCH_OUT="/private/tmp/test7-tab-colors.md" ./bin/ww-excel
```
