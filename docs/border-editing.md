# 框線編輯與預覽

第 19 項擴充儲存格格式視窗的「框線」分頁。用 ⌘1 或右鍵「儲存格格式…」開啟。

## 操作

可先選線型與線條顏色，再按外框、內框或所有框線預設；也可先按框線預設，再修改線型與色彩，最近選取的框線會即時更新預覽；亦可直接點選預覽的上、下、左、右、內部水平或內部垂直邊線。預覽旁提供對應按鈕，支援 Tab、Enter 與空白鍵。

每條邊線依序切換「套用 → 清除 → 不修改」。選了不同線型／顏色後，再點已設定的邊線會改用新的線型／顏色。「不修改」預設會清空本次框線草稿，保留原設定；「無框線」則明確清除範圍的四邊與內部框線。線型與色彩變更先留在草稿，按確定才修改文件。若只更改既有框線的線型或顏色，按確定會更新對應屬性，保留未修改的線型或色彩；沒有框線的位置不會新增框線。若另有點選預設或邊線，則依各邊草稿套用，仍可分別設定外框與內框色彩。

十三種線型包含細／中／粗實線、雙線、髮絲線、點線、虛線、中虛線、點劃線、中點劃線、雙點劃線、中雙點劃線與斜點劃線。預覽與 Canvas 共用線寬及虛線參數；自動色彩使用目前主題文字色。

所有修改保留在跨分頁草稿中，按「確定」才套用。取消或 Esc 不修改文件。

## 套用規則

- 四邊代表選取矩形的外框；內部水平／垂直代表範圍內相鄰儲存格的分隔線。單列或單欄會停用不存在的內部方向。
- 儲存格各自保存四邊，寫入或清除共用邊界時，兩側一併更新，避免被相鄰格的舊框線覆蓋。鄰格的文字、字型、填滿及其他邊線保持原狀。
- 部分碰到合併區時，將選取矩形擴展至完整合併區。合併區視為一格，內框不穿過其內部；外框同時寫入實際周邊儲存格及左上角樣式，以供 Canvas、列印及 XLSX 使用。
- 共用邊界若接到相鄰合併區，會同步該合併區的完整對應邊線。單一合併區會停用內框控制。
- 不連續選取依輸入順序各自套用外框／內框；重疊處以後套用的邊線為準。未指定的邊線保留原狀。
- 整列／整欄沿用稀疏的列欄樣式，不建立百萬格空白資料；上／下或左／右外框位於實際工作表邊緣。現有儲存格與列欄樣式交叉點保留其他格式。清除繼承的唯一框線時，保留明確的一般樣式，防止舊框線再次繼承。
- 規劃完成前不變更工作表。明確儲存格變更（含相鄰邊界）受既有一百零四萬八千五百七十六格預算限制，超限回報錯誤。
- 框線、鄰格邊界與列欄樣式由同一格式指令提交，一次復原／重做可完整還原。工具列的既有框線預設共用相同處理。

第 21 項已新增範圍外框／內框的共同與混合值彙整，預覽會標示混合邊線；淡色虛線為可操作位置提示。列印／PDF、Excel 人工比對與完整選取組合驗收仍由第 22 項追蹤。

## 1.3.2 框線顏色修正

修正開啟視窗時線條顏色固定顯示「自動」的問題，現在依選取範圍既有框線顯示共同色碼或「混合」。選色後立即更新色碼與預覽；僅改色按確定會保留既有線型、斜線及其他格式，並同步相鄰共用邊界。可改回自動色、一次復原／重做，取消及重設不會套用草稿。開啟後未改色、或選回原有共同色，不會送出只改色操作。

## 1.3.2 框線設定順序修正

補齊前次漏測的操作順序：先選外框／內框／個別邊線，再改線型或顏色，預覽與儲存結果均跟隨新設定。先改筆刷再選另一組框線時，也保留前一組已設定的線型與色彩，外框與內框仍可分別設色。既有框線可只改線型，不必重新點選邊線；混合線型顯示「混合」，不再以預設細實線代表。取消、不修改及重設均不套用待定草稿。
