# 樞紐分析表編輯

本次開發讓匯入的「工作表／表格來源」樞紐分析表可以調整欄位、篩選及重新整理。尚未提供從零建立樞紐分析表的介面。

## 操作

1. 開啟含樞紐分析表的 XLSX，切換到該工作表。
2. 點選樞紐表內的儲存格，選「資料 › 樞紐分析表…」（功能區、原生選單與儲存格右鍵選單均可使用）。工作表有多份樞紐表時，可在設定視窗選擇。
3. 將來源欄位加入列、欄、值或報表篩選區域。列／欄／報表篩選可上移、下移及移除；值欄位可新增、移除、調整順序、標題及加總／平均值／筆數。
4. 選擇是否顯示列欄位小計、橫向總計與縱向總計。欄位項目可全選、全部取消或逐項選取。
5. 按「套用並重新整理」。取消不會修改文件；計算或空間檢查失敗時，視窗會保留設定並顯示原因。

也可以直接點樞紐表標題或報表篩選的下拉按鈕，選取項目或清除篩選。這不會變更來源表格的一般篩選，也不會隱藏來源資料列。

修改來源資料後，選「資料 › 重新整理樞紐分析表」。來源為 Excel 表格時，會使用表格目前的範圍，包括新增資料列。重新整理、欄位修改與篩選各自是一個復原／重做步驟。

## 儲存與保護

- XLSX 與 WWX 保留欄位配置、彙總方式、篩選條件及已計算結果。
- 未變更的 XLSX 樞紐定義會保留。修改的樞紐會重建定義、來源項目及項目篩選；Excel 開啟時可依來源重新整理。
- 重建結果若會覆蓋相鄰資料、合併儲存格、來源資料、表格或其他樞紐表，會拒絕操作。
- 來源欄位必須有非空白且唯一的標題。來源上限為 200 萬格，結果上限為 50 萬格；值欄位最多 32 個。
- 支援普通工作表範圍、表格名稱及可解析為範圍的具名來源。不支援外部資料來源、資料模型、日期／自訂群組、計算欄位與進階「值顯示方式」；可辨識的不支援計算會保留原檔快取並禁止重新整理。
- 群組與其他進階功能的 WWX → XLSX 重建尚未支援。含有這些功能的原始 XLSX 應保留並優先原地儲存。

## 驗證

產生獨立驗收資料：

```bash
go run ./tools/pivotfixture
WW_SELFTEST=1 WW_XLSX_FIXTURE="$PWD/test_data/pivot-edit.xlsx" WW_BENCH_OUT="/private/tmp/ww-excel-pivot-selftest.md" ./bin/ww-excel
```

本次驗證：樞紐桌面 **25／25**、一般桌面 **255／255**、`test5.xlsx` 既有相容性 **53／53**、前端單元測試 **195／195** 通過；Svelte 型別檢查 0 錯誤與 0 警告，`go test ./internal/...` 通過。

自動檢查包含：來源修改後手動重新整理、下拉按鈕座標命中、篩選與一般表格隔離、欄位設定介面、加總／平均值／筆數、多值欄位、交叉彙總、報表篩選、復原／重做與 XLSX／WWX 重開。

Go 測試涵蓋：沒有符合項目的篩選、欄位順序、日期樣式與數字／文字分組、結果覆蓋保護、來源表格擴充、工作表／表格改名與列插入。若本機存在 `test_data/test5.xlsx`，另驗證啤酒 2,150、總計 5,950，來源金額 1,400 改成 2,000 後啤酒 2,750、總計 6,550 的案例。測試不覆寫原始範例檔。

Microsoft Excel 的自動開啟驗證在本機發生 AppleEvent 逾時，尚不能據此確認真正 Excel 的顯示與操作相容性；需依 `docs/manual-checks.md` 手動驗收。
