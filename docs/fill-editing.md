# 單色填滿編輯

第 20 項整合與驗證，2026-11-07。

以 ⌘1、右鍵「儲存格格式…」或工具列數值格式「其他…」開啟視窗，切換至「填滿」。可選單色或「無填滿」，跨分頁保留草稿，只有按「確定」才套用；取消、Esc 與點擊背景不套用。

預覽用棋盤背景表示透明，因此無填滿與不透明白色可明確區分，並顯示「無填滿」或實際色碼。切換分頁後焦點會移到分頁按鈕，確保可繼續使用 Tab、方向鍵與 Esc。

## 格式與顯示優先順序

格式視窗讀取儲存格的底層有效樣式（包含原有列欄樣式繼承），不將表格或條件格式的顯示色當作直接格式。這也允許在條件格式已顯示白色時，把底層填滿明確改成白色。

| 情況 | 顯示結果 |
| --- | --- |
| 命中的條件格式提供填色 | 使用條件格式顏色，保留底層直接填色 |
| 有直接單色填滿，含白色 | 直接填色優先於標準／自訂表格填色 |
| 直接格式為無填滿，且有表格樣式 | 顯示原本的表格填色或交錯列色 |
| 無直接填滿，也無表格／條件填色 | 使用畫面預設背景；PDF 不繪製填色矩形 |

「無填滿」以空字串儲存；白色以 FFFFFF 儲存並繪製不透明矩形。清除繼承的唯一填色時，使用明確的一般樣式覆寫列欄樣式，避免舊色重新繼承。未修改的字型、框線、對齊與數值格式保留。

顯示層、列印預覽、原生列印與 PDF 共用樣式疊加來源。XLSX／WWX 儲存底層格式以及原本的表格／條件格式，重開後重新計算顯示結果。

選取範圍的共同值／混合值彙整及逐欄位的明確修改追蹤已於第 21 項完成，詳見 [多選混合格式](mixed-cell-format.md)。第 22 項仍追蹤完整 Excel 人工相容性驗收。
