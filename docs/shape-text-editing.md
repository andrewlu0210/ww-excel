# 匯入文字方塊編輯

## 使用方式

- 單擊文字方塊選取；一般物件可拖曳移動，控制點可調整尺寸。
- 雙擊，或選取後按 F2／Enter，進入文字編輯。選取部分文字後使用常用工具列設定字型、大小、字色、粗體、斜體、底線與刪除線；⌘B／⌘I／⌘U 也適用。
- Enter 插入換行；⌘Enter、Tab 或「完成」提交。Esc／「取消」捨棄這次編輯。
- 編輯中可復原／重做文字及格式；完成後整次編輯成為一次文件變更。未修改就完成不增加復原紀錄。
- 點其他工作表、格線或公式列會完成文字方塊編輯；編輯時不會把文字選取當成拖曳。

數字、以 `=` 開頭的文字與 emoji 都是文字方塊內容，不會轉成儲存格公式。文字編輯沿用中文組字保護，組字期間不重建 DOM。

群組內文字可編輯，但個別子物件不能移動或縮放，避免破壞群組座標。沒有文字的線條／自訂路徑不提供文字編輯。

## 存檔與外觀

原有 XLSX 的文字修改採用 DrawingML 局部修補，保留圖形屬性、段落／清單設定、文字內距、群組容器與其他物件。文字修改不會觸發同錨點圖表的重寫。移動／縮放會同步錨點與形狀轉換，旋轉形狀也保留自身尺寸與旋轉角度。

WWX 會保存文字、格式與原始形狀 XML；轉回 XLSX 時恢復已支援的形狀外觀。群組依既有 WWX 匯出流程展平成個別物件，來源關聯無法轉移的超連結不會寫入新檔。直接編輯原有 XLSX 則保留原始群組結構及未修改物件。

新增讀取形狀樣式的填滿／邊線色彩參照，使 Excelize 產生的綠底白字文字方塊可正確顯示。
