## 重跑

測試檔 `test_data/test5.xlsx` 不納入 Git。以下會執行同一活頁簿的圖表與樞紐顯示檢查，並將副本、報告及 PNG 寫到指定的暫存目錄。

```sh
mkdir -p /private/tmp/ww-excel-test5
WW_SELFTEST=1 \
WW_XLSX_FIXTURE="$PWD/test_data/test5.xlsx" \
WW_BENCH_OUT=/private/tmp/ww-excel-test5/report.md \
./bin/ww-excel
```

## 限制

這次支援既有樞紐結果的顯示及部分自訂樣式；尚不支援建立樞紐分析表、調整欄位、操作樞紐下拉篩選或重新整理結果。沒有使用真正 Excel 重開副本驗證。作業系統字型替代仍可能造成字距與換行差異。
