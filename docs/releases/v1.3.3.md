# WW Excel v1.3.3

版本日期：2026-11-08

本版修正公式列的編輯焦點與函數建議操作，讓公式列可以持續編輯，並完整瀏覽及選取符合的函數。

## 公式列編輯

- 點入 fx 後的輸入框，游標留在公式列，輸入內容即時預覽於儲存格。
- 公式列編輯期間，儲存格只顯示草稿，不接受編輯或 Tab 焦點；一般焦點還原及儲存格取焦不再搶走公式列焦點。
- 保留文字中間插入、滑鼠選取、公式參照點選、富文字及中文組字；Enter 提交、Esc 取消後恢復儲存格編輯。

## 函數建議

- 修正放開上下鍵時重建建議清單，導致選取跳回第一項的問題。
- 上下鍵可連續及循環選取，Tab 插入目前選取的函數；Esc 關閉建議後不會立即重新開啟。
- 移除前 10 項限制，完整列出符合前綴的函數與名稱。例如輸入 `=P`，可以找到原本被截掉的 `PRODUCT`。
- 清單支援捲動；鍵盤選取會自動將對應項目捲入可視範圍，只捲動建議清單，保留工作表位置及公式列焦點。

## 安裝

1. 下載 `WW-Excel-1.3.3.dmg`，儲存並關閉舊版 WW Excel，再將 App 拖進「應用程式」取代舊版。
2. 本版為 Universal App，包含 Apple Silicon（arm64）與 Intel（x86_64）架構。
3. 沿用 ad-hoc 簽章，未經 Apple 公證；若 macOS 阻擋開啟，請依系統「隱私權與安全性」提示處理。

另附 `WW-Excel-1.3.3.dmg.sha256`。將兩個檔案下載至同一目錄後，可驗證：

```sh
shasum -a 256 -c WW-Excel-1.3.3.dmg.sha256
```
