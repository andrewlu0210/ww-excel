# WW Excel v1.3.0

版本日期：2026-11-06

本版著重改善與 Mac Microsoft Excel 的顯示比例、開檔視窗及窄視窗工具列體驗，並補強檔案匯入、公式計算與測試介面的安全性。

## 顯示與操作改善

### 工作表顯示更接近 Mac Excel

- 修正相同縮放百分比下，工作表內容比 Mac Microsoft Excel 明顯偏大的問題。
- 統一調整儲存格、文字、選取框、圖片及圖表的顯示比例，同步校正點選、編輯、物件操作與「選取範圍最適化」的座標換算。
- 修正部分縮放比例下，捲動位置取整造成的偏移，涵蓋凍結窗格、隱藏列欄及工作表最末端。
- 此調整作用於螢幕顯示，保留檔案中的縮放百分比、字級、列高、欄寬與物件尺寸；列印輸出維持原有尺寸。

### 套用 XLSX 記錄的視窗大小與位置

- 開啟 XLSX 時，讀取檔案記錄的視窗寬高與桌面座標，支援建立新視窗及沿用空白視窗開檔。
- 依目標螢幕的可用範圍調整位置及大小，避開選單列與 Dock；記錄位置已不在目前桌面範圍時，回到目前螢幕。
- 支援零座標、負座標與多螢幕配置；缺少或無效的記錄不覆蓋既有視窗設定。
- 修正 Retina 螢幕混用實體像素與邏輯座標，造成開檔 Y 座標額外下移的問題。
- 已開啟的同一檔案再次開啟時，聚焦原視窗，保留使用者目前調整的位置及大小。

### 改善窄視窗工具列

- 縮窄視窗時，功能區維持固定高度，工具群組不再換行將工具列撐高。
- 工具列內容超出寬度時，可透過左右按鈕、觸控板或滑鼠滾輪水平捲動。
- 修正左右捲動按鈕被工具列內容遮住、僅偶爾閃現的問題。
- 字型色彩、填滿色彩、框線及清除選單改用浮動顯示，避免被捲動區裁切；支援捲動、調整視窗及按 Esc 關閉選單。

## 開檔與公式穩定性

### 可取消的 WWX／XLSX 匯入

- 開檔期間顯示載入視窗，可按「取消」或 Esc 中止匯入。
- 加入壓縮檔大小、解壓後總量、單一零件、文字、資料筆數、公式複雜度及圖形資源限制；超限時顯示明確原因。
- 完成解析及公式計算後才套用新文件。取消或失敗時保留原文件、未儲存內容與復原紀錄，並清理暫存資源。
- 同一視窗開始新的匯入時，取消舊工作；較晚完成的舊結果，以及視窗關閉後才完成的結果，都不會覆蓋目前文件。

### 修正公式錯誤後的鎖定問題

- 修正 `REPT` 長度檢查的整數溢位，避免特定輸入造成程式異常。
- 單一公式求值發生可回復的異常時，回傳 `#VALUE!`，讓其他公式及後續操作繼續完成；平行計算也採用相同保護。
- 改善文件鎖釋放及事件發送順序，避免異常後無法查詢狀態、繼續編輯或儲存。
- 驗證錯誤公式的復原／重做，以及 XLSX／WWX 儲存重開後的內容與狀態一致性。

## 安全性補強

- 更新 Excelize，納入畸形樞紐分析表索引問題的上游修補（`GO-2026-6695`），並檢查樞紐欄位與快取欄位的一致性。
- 隔離 XLSX 解析的非預期異常；開啟畸形檔案時安全回報錯誤，不回傳部分載入的文件。
- 在大量配置記憶體前，預檢 WWX 字串與 JSON 結構，以及 XLSX 的實際 ZIP 記錄、解壓資料和 XML，涵蓋自訂 XML 與圖形零件。
- 一般模式禁止透過測試專用 bindings 寫檔、推送測試事件、執行公式鏈重算或強制 GC。
- 測試模式加入參數、輸出大小、圖片尺寸與並行工作限制；一般模式的效能 HUD 隱藏量測按鈕。

## 相容性與效能說明

- 本版新增匯入安全限制：壓縮輸入上限為 256 MiB、解壓後總量為 512 MiB、實際儲存格上限為 2,000,000 格；各項限制會同時生效，部分超大型文件可能無法開啟。完整預算見[匯入限制說明](../import-limits.md)。
- 安全預檢會增加大檔開啟成本。Apple M2 Max 上的百萬格 XLSX 測試，額外預檢約增加 1.5 秒純讀取時間；完整開檔與公式重算約 3.05 秒。此為特定測試檔的量測，實際時間依檔案內容及設備而異。
- 取消採合作式檢查；第三方解析、檔案寫入等進行中的步驟，可能需要稍候才停止。2 分鐘的開檔取消期限不代表能強制立即終止所有底層操作。
- 視窗幾何目前支援從 XLSX 讀取；手動調整後的位置與大小尚未寫回檔案。
- 顯示比例以接近 Mac Excel 為目標；不同字型、文件及圖表的完整畫面仍需持續比對。

## 驗證結果

- 完整 Go 測試及相關 data race 檢查通過。
- 前端單元測試 **246／246** 通過；Svelte／TypeScript 檢查為 **0 錯誤、0 警告**，正式建置通過。
- 桌面自動回歸 **300／300** 通過，涵蓋縮放、工具列、編輯、公式錯誤、存檔重開及測試 bindings。
- 百萬格開檔取消流程 **9／9**、樞紐分析表編輯與存檔往返 **25／25**、`test8.xlsx` 視窗位置與大小驗證 **5／5** 通過。
- 完整 benchmark 通過；三組事件測試皆收到預期數量，1,000／10,000／100,000 格公式鏈、記憶體量測、截圖及報告輸出正常。
- 重掃結果：正式 npm 相依 **0 個警示**；建置工具仍有同一則 Low 公告影響 2 個套件。Go 一般與 production 模式均剩 3 則警示，未找到受影響函式的可達呼叫鏈。

## 持續追蹤

- 第 17 項保留為低優先維護：Go 相依可安排升級與回歸；前端 `deepmerge` 尚待上游提供修補版本。本次重掃沒有升級這些相依。
