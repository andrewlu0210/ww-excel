## 更新內容

- 修正匯出 XLSX 在 Microsoft Excel 開啟時要求修復：清除散佈圖數值軸中不合法的類別軸欄位，並依圖表類型處理 Office 支援的資料標籤位置。介面也只顯示適用的位置選項。
- 修正圖表在 Excel 縮成儲存格大小：改用明確 EMU 寬高的單一儲存格錨點，保留格內偏移及 XLSX／WWX 往返後的尺寸。
- 修正自訂標籤混入圖例鍵、額外數值與其他自動內容；補齊中文字型、置中及固定行距，並將段落設定保存於標籤文字框，避免 Excel 重存後再次錯位。
- 對齊 Excel 的預設淡灰色圖表外框；明確設定無外框的圖表仍保持無框，自訂外框色彩也會保存。

## 安裝

1. 下載 `WW-Excel-1.2.9.dmg`，將 WW Excel 拖進「應用程式」取代舊版，關閉舊版後重新啟動。
2. 本版為 Universal App，包含 Apple 晶片及 Intel 版本。
3. 沿用 ad-hoc 簽章，未經 Apple 公證；若 macOS 阻擋開啟，請依系統「隱私權與安全性」提示處理。

另附 `WW-Excel-1.2.9.dmg.sha256`，將兩個檔案下載至同一目錄後驗證：

```sh
shasum -a 256 -c WW-Excel-1.2.9.dmg.sha256
```
