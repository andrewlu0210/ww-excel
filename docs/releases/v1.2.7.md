## 更新內容

- 匯入的工作表／表格來源樞紐分析表可調整列、欄、值與報表篩選欄位，新增、移除及調整欄位順序，支援加總、平均值、筆數、列欄位小計及總計。
- 樞紐表下拉按鈕可選取項目、全選與清除篩選；與來源表格的一般篩選分開管理。
- 修改來源資料後可手動重新整理，納入來源表格新增資料列；欄位修改、篩選及重新整理支援復原／重做、XLSX／WWX 儲存與重開。
- 結果擴充時檢查相鄰資料、合併儲存格、來源、表格及其他樞紐表，避免覆蓋內容；保留跨工作表來源改名及列插入後的參照。
- 修正工作表分頁右鍵「刪除／左移／右移」無作用，保留至少一張可見工作表的限制。
- 更新圖示回歸測試，對齊既有的透明 Dock 留白設計。

## 使用方式

開啟含樞紐分析表的 XLSX，切換到該工作表，選擇「資料 › 樞紐分析表…」或「資料 › 重新整理樞紐分析表」。也可使用儲存格右鍵選單與樞紐表下拉按鈕。

操作與限制：[樞紐分析表編輯](https://github.com/andrewlu0210/ww-excel/blob/v1.2.7/docs/pivot-editing.md)。

## 安裝

1. 下載 `WW-Excel-1.2.7.dmg`，將 WW Excel 拖進「應用程式」取代舊版，關閉舊版後重新啟動。
2. 本版為 Universal App，支援 Apple 晶片及 Intel Mac；專案設定的最低系統版本為 macOS 12。
3. 沿用 ad-hoc 簽章，未經 Apple 公證；若 macOS 阻擋開啟，請依系統「隱私權與安全性」提示處理。

另附 `WW-Excel-1.2.7.dmg.sha256`。將兩個檔案下載至同一目錄後驗證：

```sh
shasum -a 256 -c WW-Excel-1.2.7.dmg.sha256
```
