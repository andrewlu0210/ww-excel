## 更新內容

- 新增進階圖表資料標籤：數值、百分比、類別、數列名稱、自訂文字與格式；支援個別位置及滑鼠拖曳、Escape 取消、復原／重做。
- 新增座標軸設定：範圍、刻度、數字格式、字型、軸線及格線；組合圖左右軸、散佈圖 X／Y 軸可獨立設定。
- 新增數列外觀設定：色彩、折線粗細、資料點標記、柱距與環圈內徑，提供即時預覽及 XLSX／WWX 保存。
- 匯入圖表的標籤、座標軸及數列外觀以局部 XML 更新，保留未修改的圖表樣式、擴充節點與資源，減少不必要的相容性提示。
- 支援 Excel 工作表分頁色彩，包含主題色與明暗調整；右鍵可選色及清除，支援復原／重做、改名移動及 XLSX／WWX 保存。
- 合併連續相同的欄樣式寫入，改善整張工作表套用欄格式時 WWX → XLSX 的匯出速度。

## 使用方式

雙擊圖表開啟設定；點選並拖曳資料標籤可調整個別位置。在底部工作表分頁上按右鍵，選「分頁色彩…」設定顏色，或以「無色彩」清除。

操作說明：[資料標籤](https://github.com/andrewlu0210/ww-excel/blob/v1.2.8/docs/chart-labels.md)、[座標軸](https://github.com/andrewlu0210/ww-excel/blob/v1.2.8/docs/chart-axes.md)、[數列外觀](https://github.com/andrewlu0210/ww-excel/blob/v1.2.8/docs/chart-series.md)、[分頁色彩](https://github.com/andrewlu0210/ww-excel/blob/v1.2.8/docs/sheet-tab-colors.md)。

## 安裝

1. 下載 `WW-Excel-1.2.8.dmg`，將 WW Excel 拖進「應用程式」取代舊版，關閉舊版後重新啟動。
2. 本版為 Universal App，包含 Apple 晶片及 Intel 版本。
3. 沿用 ad-hoc 簽章，未經 Apple 公證；若 macOS 阻擋開啟，請依系統「隱私權與安全性」提示處理。

另附 `WW-Excel-1.2.8.dmg.sha256`。將兩個檔案下載至同一目錄後驗證：

```sh
shasum -a 256 -c WW-Excel-1.2.8.dmg.sha256
```
