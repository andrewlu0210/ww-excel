# WW Excel v1.3.1

版本日期：2026-11-06

本版修正 XLSX 圖片裁切與圖文框文字溢出的顯示問題，改善與 Microsoft Excel 的相容性。

## 圖片裁切修正

- 修正開啟含裁切圖片的 XLSX 時，忽略裁切設定、將整張原圖壓入顯示框，造成圖片變形的問題。例如 `test9.xlsx` 右上角 Logo 原先會出現上下壓縮。
- 支援讀取一般圖片及群組內圖片的裁切範圍，先套用裁切，再依物件尺寸顯示；列印也使用裁切後的圖片。
- 儲存為 WWX 時保留原始圖片與裁切資訊；需要重新寫入圖片的 XLSX 匯出，則使用已套用裁切的圖片，保留顯示效果。

## 圖文框文字顯示修正

- 修正忽略文字框垂直溢出裁切設定，導致超出高度的文字仍顯示在第二行，並影響整段文字垂直置中的問題。例如 `test9.xlsx` 左上方標題的「评估」原先會換行顯示在圖示附近。
- 依文字框可用高度隱藏放不下的完整文字行，再對可見文字套用垂直置中，讓顯示更接近 Microsoft Excel。
- 裁切僅影響顯示，檔案中的完整文字仍會保留。

## 相容性說明

- 不同字型及文件的完整畫面仍需持續與 Microsoft Excel 比對；本版未重新執行完整桌面自動回歸。

## 安裝

1. 下載 `WW-Excel-1.3.1.dmg`，關閉舊版 WW Excel，再將 App 拖進「應用程式」取代舊版。
2. 本版為 Universal App，包含 Apple 晶片（arm64）及 Intel（x86_64）版本。
3. 沿用 ad-hoc 簽章，未經 Apple 公證；若 macOS 阻擋開啟，請依系統「隱私權與安全性」提示處理。

另附 `WW-Excel-1.3.1.dmg.sha256`，下載兩個檔案至同一目錄後，可執行：

```sh
shasum -a 256 -c WW-Excel-1.3.1.dmg.sha256
```
