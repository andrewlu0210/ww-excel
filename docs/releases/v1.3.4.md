# WW Excel v1.3.4

版本日期：2026-11-13

本版將 Wails 升級為 `v3.0.0` 正式版，並修正右鍵刪除整列後公式候選清單消失的問題。

## 更新內容

- Wails Go module、`@wailsio/runtime` 與 CLI 同步固定為 `3.0.0`。
- 修正「儲存格右鍵 → 刪除… → 整列 → 確定」後浮層的掛載位置被移除，造成公式候選與參數提示無法顯示。
- 刪列後輸入 `=P` 可繼續瀏覽完整候選清單，並使用方向鍵與 Tab 選取函數。
- 同步更新執行檔預設版本、正式與開發 App bundle，以及建置設定為 `1.3.4`。

## 驗證與限制

- Wails 升級後的完整 Go 測試與前端 294 項測試通過，型別檢查為 0 錯誤、0 警告。
- 右鍵刪列專用桌面回歸 26／26 通過，包含原生 contenteditable 輸入、清單可見性、命中測試、鍵盤選取與參數提示。
- 使用者已確認升級後版本可用。
- 完整桌面 self-test 仍受升級前即存在的格式視窗測試選取器錯誤阻擋；不得視為完整桌面驗收通過。
- 詳見 [Wails 升級紀錄](../wails-v3-upgrade.md) 與 [右鍵刪列修正紀錄](../formula-assist-context-menu.md)。

## 本機安裝產物

`dist/WW-Excel-1.3.4.dmg` 與對應的 `.sha256` 校驗檔。App 採 ad-hoc 簽章，未經 Apple 公證；本次僅產生本機驗收檔案，尚未對外發布。
