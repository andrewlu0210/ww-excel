# 多選混合格式與一次套用／復原

第 21 項：選取一格、多格或不連續範圍後，透過 ⌘1／右鍵開啟儲存格格式視窗。

## 混合值與差異套用

視窗彙整底層格式，包含空白格與列欄樣式繼承；條件格式與表格顯示覆蓋不會成為直接格式。整列、整欄或整張工作表使用稀疏區域計數，不逐格建立或掃描空白資料。

- 字型、字級、字型色彩、數值格式、填滿、水平／垂直對齊會分別顯示共同值或「混合」。
- 粗體、斜體、底線、刪除線及換行的混合值顯示中間勾選狀態。富文字區段也納入字型屬性的彙整。
- 框線依外框四邊與內部水平／垂直邊線彙整，合併儲存格視為一格；混合邊線保留至使用者明確設定或清除。
- 只送出使用者實際修改的欄位。修改混合欄位時，即使所選值等於其中一格原值，也會明確套用到全部選取格；其他欄位保持原狀。
- 「重設變更」還原本次草稿及混合狀態。共同欄位改動後又改回原值不送出；未修改、取消或沒有實際變更時不新增文件版本、Dirty 狀態或復原紀錄。

例如選取紅色／藍色填滿、不同字型及數值格式的兩格，只改成黃色填滿，兩格各自的字型、數值格式與框線仍保留。作用中儲存格原本已無填滿，仍可對混合範圍按「無填滿」清除其他格的填色。

## 原子提交與列高

跨分頁變更由同一格式指令提交。變更字型、字級、粗體／斜體、換行或數值格式時，先以投影後的樣式量測文字，再把自動列高與格式放入同一復原指令；一次復原／重做包含格式、共用框線、列欄樣式及本次自動列高。

量測會考慮同列未選取的文字、富文字區段與水平合併寬度，並保留手動列高。沿用既有自動列高範圍限制：僅處理未設定列高且選取高度不超過約 500 列的範圍；多範圍合計最多 512 個自動量測列。跨列合併不自動改列高。列高最高 546px。

格式與列高在規劃及驗證完成後才修改文件，失敗不會留下部分格式。量測期間文件被替換時，已卸載的視圖不會將結果套用到新文件。
