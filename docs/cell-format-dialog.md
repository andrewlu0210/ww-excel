# 統一儲存格格式視窗

第 18 項第一階段介面整合，2026-11-07 實作。

選取儲存格後，按 ⌘1、右鍵選「儲存格格式…」，或使用工具列數值格式的「其他…」，均開啟同一視窗。

- 數值：保留原有分類、自訂格式碼與 Go 計算的作用中儲存格預覽。
- 字型：字型、字級、粗體、斜體、底線、刪除線、文字色彩與文字預覽。
- 對齊：水平／垂直對齊與自動換行。
- 框線：整合既有工具列預設與線條顏色；預設為「不修改」。個別邊線、內框、線型與互動預覽已於第 19 項擴充，詳見 [框線編輯與預覽](border-editing.md)。
- 填滿：整合既有單色選擇、無填滿與色彩預覽；空字串代表無填滿，FFFFFF 代表白色；棋盤預覽、底層格式與顯示優先順序已於第 20 項完成，詳見 [單色填滿編輯](fill-editing.md)。

分頁使用同一份草稿，切換時保留編輯。只有按「確定」才送出已變更屬性；取消、Esc、點擊背景或未修改直接確定，都不送出格式指令。色盤開啟時 Esc 先關閉色盤，再按 Esc 關閉視窗。數值預覽會忽略過期結果，預覽失敗會顯示提示。

Tab／Shift-Tab 在視窗內循環；分頁可使用左右方向鍵、Home／End。小視窗下內容可捲動，底部操作按鈕保留於畫面內。無效字級即使切換分頁也不能提交。

第 21 項已完成選取範圍的共同／混合格式彙整、實際修改欄位追蹤與含自動列高的單筆復原，詳見 [多選混合格式與一次套用／復原](mixed-cell-format.md)。第 22 項仍追蹤完整相容性與人工驗收。
