# 統一儲存格格式視窗

第 18 項第一階段介面整合，2026-11-07 實作。

選取儲存格後，按 ⌘1、右鍵選「儲存格格式…」，或使用工具列數值格式的「其他…」，均開啟同一視窗。

- 數值：左側依數值用途分類，日期／時間的各種顯示方式集中於右側「類型」，保留自訂格式碼與 Go 計算的作用中儲存格預覽。
- 字型：字型、字級、粗體、斜體、底線、刪除線、文字色彩與文字預覽。
- 對齊：水平／垂直對齊與自動換行。
- 框線：整合既有工具列預設與線條顏色；預設為「不修改」。個別邊線、內框、線型與互動預覽已於第 19 項擴充，詳見 [框線編輯與預覽](border-editing.md)。
- 填滿：整合既有單色選擇、無填滿與色彩預覽；空字串代表無填滿，FFFFFF 代表白色；棋盤預覽、底層格式與顯示優先順序已於第 20 項完成，詳見 [單色填滿編輯](fill-editing.md)。

分頁使用同一份草稿，切換時保留編輯。只有按「確定」才送出已變更屬性；取消、Esc、點擊背景或未修改直接確定，都不送出格式指令。色盤開啟時 Esc 先關閉色盤，再按 Esc 關閉視窗。數值預覽會忽略過期結果，預覽失敗會顯示提示。

Tab／Shift-Tab 在視窗內循環；分頁可使用左右方向鍵、Home／End。小視窗下內容可捲動，底部操作按鈕保留於畫面內。無效字級即使切換分頁也不能提交。

第 21 項已完成選取範圍的共同／混合格式彙整、實際修改欄位追蹤與含自動列高的單筆復原，詳見 [多選混合格式與一次套用／復原](mixed-cell-format.md)。第 22 項仍追蹤完整相容性與人工驗收。

## 日期與時間分類調整（2026-11-08）

左側僅保留一個「日期」及一個「時間」。選日期後，右側「類型」提供西元數字日期、ISO 日期、西元中文日期、民國數字日期與民國中文日期；「上午／下午」則放在時間類型中。選取類型會同步格式碼與預覽，確定後才套用。

重新開啟既有日期格式會選中原有類型，不會重設為預設西元日期。未列出的格式放在「自訂」，原碼保持不變；混合格式不會假裝具有共同類型。切換分頁保留分類與草稿，取消及僅檢視自訂分類不產生修改。

## 中文數字日期與星期類型（2026-11-08）

日期類型新增 `3月14日`、`二○一二年三月十四日`、`三月十四日`、`星期三` 與 `週三`。中文數字年月日使用 `[DBNum1][$-404]yyyy"年"m"月"d"日"`／`[DBNum1][$-404]m"月"d"日"`，繁體星期使用 `[$-404]dddd`／`[$-404]ddd`；類型清單最多顯示八列，可捲動選取其餘格式。

格式引擎針對日期欄位轉換中文數字：年份逐位顯示（零為 `○`），月／日使用十進位中文數詞（十、十四、二十等），不會改寫引號內的數字文字。沒有台灣語系標記的既有英文星期格式保持原行為。預覽、儲存格、列印來源及 PDF 共用相同日期格式處理；XLSX／WWX 會保留原始格式碼與數值。

新增數值格式邊界、閏日、七天星期及服務層預覽／顯示／列印／檔案往返回歸。本次未關閉使用者正在操作的 Excel 格式視窗進行額外原生比對。
