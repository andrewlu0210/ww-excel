# 手動確認清單

self-test 模擬不了原生 IME、選單操作、系統剪貼簿與其他 app 的互動，也不會開新視窗。這些項目要用 `wails3 build` 出來的 `bin/ww-excel` 實際操作確認。

- 確認通過後把 `[ ]` 改成 `[x]`，並在後面註明日期；發現問題就記在該項底下
- 每完成一版就在最後加一節，列出新的待確認項目
- 每版都要重測的項目放在「每版必測」

---

## 每版必測

- [ ] **注音輸入**：在儲存格直接打字，第一個按鍵就進入組字，候選字視窗出現在儲存格旁；選字後 Enter 提交、方向鍵移動
- [ ] **倉頡輸入**：同上
- [ ] **公式列中文輸入**：點公式列後以注音輸入，候選字視窗位置正確
- [ ] **選單快捷鍵**：⌘Z / ⇧⌘Z / ⌘S / ⌘O / ⌘N / ⌘W / ⌘1 / ⌘B 從鍵盤與從選單點選都只執行一次
- [ ] **⌘Q 有未儲存的文件**：會詢問是否儲存；按「取消」不會結束程式

## v0.5（生產力操作）

### 剪貼簿

- [ ] **從本程式複製到 Excel**：⌘C 一個含數字、文字、公式的範圍，在 Excel 貼上，值正確；確認 Excel 有沒有收到 HTML 格式（粗體、填色是否帶過去）
- [ ] **從 Excel 複製到本程式**：在 Excel ⌘C 一個範圍（含換行、Tab 的儲存格），在本程式 ⌘V，資料位置與內容正確
- [ ] **從其他 app 貼上**：從 Numbers、網頁表格、純文字編輯器各貼一次
- [ ] **編輯選單用滑鼠點選**：「編輯 › 剪下 / 拷貝 / 貼上」在閒置時作用在儲存格，在編輯中作用在文字；選單項目不是灰色
- [ ] **編輯中的 ⌘C / ⌘V**：編輯儲存格或公式列時，⌘C / ⌘V 只處理選取的文字
- [ ] **兩個視窗之間複製貼上**：公式與格式會帶過去
- [ ] **⌘V 只執行一次**：快速按 ⌘V，不會貼兩次

### 填滿、插入、刪除

- [ ] **實際拖曳填滿控點**：滑鼠游標移到控點會變十字，拖曳時有虛線預覽，往回拖會清除
- [ ] **雙擊填滿控點**：會填到相鄰資料的最後一列
- [ ] **⇧⌘= / ⌘-**：整列、整欄選取時直接插入或刪除；一般儲存格選取時出現「整列 / 整欄」對話框
- [ ] **右鍵選單**：在儲存格、列標題、欄標題上按右鍵（也試 ⌃點按），項目正確且可以執行

### 凍結、隱藏、篩選、排序、尋找

- [ ] **凍結窗格**：凍結後捲動，凍結的列欄固定不動；拖曳選取跨過凍結線時會自動捲動
- [ ] **凍結窗格存到 xlsx 後用 Excel 開啟**：凍結位置相同
- [ ] **篩選下拉選單**：點按鈕出現清單，搜尋、全選、確定、取消、排序都正常；篩選中的欄顯示漏斗
- [ ] **篩選存到 xlsx 後用 Excel 開啟**：篩選範圍與隱藏列正確
- [ ] **⌃9 / ⌃0 隱藏列欄**：macOS 可能把 ⌃0、⌃9 等組合鍵留給系統（輸入法切換、Mission Control），確認有沒有被攔走
- [ ] **排序對話框**：多層排序、勾選/取消「我的資料有標題」時欄名清單跟著變
- [ ] **尋找與取代面板**：Enter 找下一個、⇧Enter 找上一個、Esc 關閉；「整個活頁簿」會切換到其他工作表；全部取代後顯示筆數

### 多視窗與檔案

- [ ] **⌘N 開新視窗**：新視窗位置錯開，標題是「未命名」
- [ ] **開啟檔案**：目前是沒動過的新文件時直接開在同一個視窗，否則開新視窗；開啟已經開著的檔案會切到那個視窗
- [ ] **各視窗互不干擾**：在 A 視窗編輯，B 視窗的格線、復原選單、標題不受影響；切換視窗時「復原」選單的文字跟著變
- [ ] **關閉視窗**：有未儲存變更時詢問；關掉最後一個視窗會結束程式
- [ ] **⌘Q 有多個未儲存的視窗**：逐一詢問，任何一個按「取消」就停止結束
- [ ] **最近使用的檔案**：開檔、存檔後出現在選單最上面；點選可開啟；檔案已刪除時會從清單移除；「清除最近使用的檔案」有效
- [ ] **Finder 開檔**：要用打包好的 `.app` 測（`wails3 package` 或 `build/` 的 app bundle），在 Finder 對 xlsx / csv / wwx 選「打開方式 › WW Excel」，以及拖到 Dock 圖示

### 跨工作表參照

- [ ] **點選其他工作表**：在 A1 輸入 `=SUM(`，點「工作表2」分頁，拖曳選取 B2:B5，畫面只剩公式列在編輯；按 Enter 回到原工作表，公式是 `=SUM(工作表2!B2:B5)`
- [ ] **中途按 Esc**：取消後回到原工作表，儲存格沒有變

- [ ] **⇧F2 插入註解**：編輯框出現在儲存格旁，⌘Enter 或「儲存」寫入、Esc 取消；作者是 macOS 使用者全名
