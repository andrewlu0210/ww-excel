# 手動確認清單

self-test 模擬不了原生 IME、選單操作、系統剪貼簿與其他 app 的互動，也不會開新視窗。這些項目要用 `wails3 build` 出來的 `bin/ww-excel` 實際操作確認。

- 確認通過後把 `[ ]` 改成 `[x]`，並在後面註明日期；發現問題就記在該項底下
- 每完成一版就在最後加一節，列出新的待確認項目
- 每版都要重測的項目放在「每版必測」

## 儲存相容性提示

- [x] **CSV 風險與取消**：建立含兩張工作表、公式、日期格式與圖表的文件，另存 CSV；確認列出第一張工作表及各項影響，預設按鈕為取消。取消後原檔、文件路徑與未儲存狀態不變。
- [x] **繼續與再次提醒**：接受 CSV 儲存後，同位置及相同影響不重複詢問；新增另一類影響、換儲存位置或關閉重開文件後會重新提示。儲存失敗時，下次仍須確認。
- [x] **另存副本**：CSV 提示選「另存副本…」，預設名稱為 XLSX；儲存成功後原檔保持不變。若選到原始檔案，應拒絕覆蓋；取消選檔不應儲存或關閉文件。
- [x] **XLSX 圖表**：開啟有圖表的 XLSX，只改資料格不提示；僅調整匯入圖表的大小、位置、標題、參照或標籤後，應保留原格式且不提示；更換圖表類型或增刪數列等結構變更後，儲存時顯示工作表、圖表名稱與物件編號；復原結構變更後不提示。
- [x] **儲存後關閉**：文件有未儲存變更時關閉視窗，選擇儲存，再取消相容性提示；視窗應保持開啟且仍為未儲存。
- [x] **語系**：繁體中文、簡體中文與英文的提示、選項、預設副本名稱均正確。

以上可在未安裝 Excel 的環境驗收；真正 Excel 的開啟、重算與版面互通仍屬未驗證。

## 富文字編輯格式保留

- [x] **儲存格與公式列編輯**：開啟含「紅色粗體標題＋黑色內文」的 XLSX，分別在儲存格與公式列修改內文，提交後標題格式保留；取消編輯不改變內容與格式。
- [x] **中文與區段邊界**：分別以注音與倉頡輸入，測試插入、選字、取消組字、刪除與跨區段取代；區段交界插入繼承左側格式，開頭插入繼承首字格式，替換繼承被移除首字格式。另確認 Emoji 與換行後文字正確。
- [x] **復原與重做**：修改不同格式區段後，⌘Z 還原原始文字及格式，⇧⌘Z 恢復修改；未改內容直接提交不增加復原步驟。
- [x] **Excel 互通**：編輯後原地儲存、另存 XLSX，以及 XLSX → WWX → XLSX，重開與用真實 Excel 開啟後，文字與各區段字型、大小、顏色及粗體／斜體／底線／刪除線一致。

### 多視窗與檔案

- [x] **⌘N 開新視窗**：新視窗位置錯開，標題是「未命名」

- 原因：Excelize 的 `oneCell` 模式產生 `twoCellAnchor`，卻讓右下角維持在起點儲存格，僅以大偏移量表示尺寸；Excel 會限制這些偏移。現改為真正 `oneCellAnchor`，用明確 EMU `ext` 保存寬高，並補償新建圖表起點的格內偏移。
- [x] **Excel 實際尺寸**：`chart-input-size-fixed.xlsx` 由 Excel 16.114.3 開啟後，四張圖表分別為 480×270、450×255、450×255、375×225 點，對應 WW Excel 的 640×360、600×340、600×340、500×300 像素。
- [x] **Excel 重存尺寸**：由 Excel 另存為 `chart-input-size-excel-roundtrip.xlsx` 再開啟，四張圖表數量及上述尺寸保持一致。
- 新增非零起點偏移、明確 extent、重複保存及 XLSX／WWX 往返的回歸測試。原始檔案保留。

## 圖表預設外框（2026-11-05）

- 使用者回報 Excel 有圖表淡灰外框，WW Excel 卻沒有。原因為未指定線條色彩時，WW Excel 將 Office 的自動外框當成無外框。
- 匯入未明確指定外框的圖表時，使用 `D9D9D9`；明確 `a:ln/a:noFill` 仍為無外框。新建圖表的預設同樣使用淡灰色。
- 重新產生圖表 XML 時，依模型明確寫入外框色彩或無外框，避免 Excel 自動補出與畫面不同的框線。
- Go 回歸涵蓋自動外框、明確無框、自訂色彩及新建圖表往返。
