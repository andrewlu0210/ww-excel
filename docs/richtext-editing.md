# 富文字局部編輯

## 操作

1. 雙擊儲存格、按 F2，或點擊公式列進入編輯。
2. 用滑鼠或 Shift＋方向鍵選取部分文字。
3. 從常用工具列設定字型、大小、字色、粗體、斜體、底線或刪除線；⌘B／⌘I／⌘U 也會套用到選取區段。
4. 按 Enter／Tab 提交；Escape 同時捨棄這次的文字與格式修改。

游標沒有選取文字時，變更格式會套用到後續輸入；移動游標後恢復該位置的格式。插入文字繼承左側格式，開頭插入繼承首字格式；替換選取文字繼承第一個被移除字元的格式。公式維持一般公式編輯，不加入分段字型；數值可使用整格字型格式。

儲存格編輯器即時顯示實際字型與字級。公式列保留區段的字型、字色與裝飾，但使用固定顯示大小，實際字級由工具列顯示。中文組字期間不重建編輯區 DOM，也不攔截組字按鍵，完成組字後才更新草稿。貼上只接收純文字，保留換行並依插入位置繼承格式。

編輯中可復原／重做文字及格式，儲存格與公式列共用同一份紀錄。提交後，文字與格式成為同一次文件變更；自動列高的增加也一起復原。手動設定的列高不會被改寫。
