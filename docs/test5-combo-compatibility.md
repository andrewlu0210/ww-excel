# 柱狀＋折線雙軸組合圖

2026-11-03，以 `test_data/test5.xlsx`「9.圖表」下方的原始圖表 XML、資料及實際 Canvas 畫面驗證。

## 行為

- 同一圖表可同時繪製直條與折線，每個數列分別指定主座標軸或次座標軸。插入／編輯圖表視窗提供組合圖類型與每個數列的類型、座標軸設定，預覽使用同一套繪製流程。
- 匯入時依 plot 的 `axId` 配對座標軸，再依數列索引恢復圖例順序；不以 XML 元素出現順序推測左右軸。
- 左右軸獨立計算範圍與刻度，套用各自的數字格式，保留明確指定的上下限、刻度間距、軸線、標籤隱藏及字型設定。
- 折線與柱狀共用類別中心位置。折線缺值保留缺口，原檔指定無標記時不添加圓點；折線圖例使用線段。
- 修改來源資料或圖表設定後更新顯示，支援復原／重做。調整大小造成 XLSX 圖表重寫時，仍保留兩組 plot、主次軸歸屬、折線顏色與線寬。WWX 保存相同的模型設定。
